# Travel Agent

Учебный CLI-агент для планирования путешествий на Go. Пользователь описывает поездку обычным текстом, LLM определяет необходимые действия, вызывает инструменты и формирует итоговый ответ на русском языке.

Отели и транспорт агент ищет в локальной SQLite-базе с вымышленными данными. Инструмент погоды пока возвращает тестовый прогноз. Проект демонстрирует agent loop, tool calling, историю диалога, работу с OpenAI-compatible API и базой данных.

> Все варианты отелей, транспорта, цены и прогнозы в проекте вымышлены и не подходят для планирования реальной поездки.

## Возможности

- диалог с сохранением истории в рамках запущенного процесса;
- OpenAI-compatible Chat Completions API;
- автоматическая загрузка настроек из `.env`;
- tool calling с JSON Schema;
- поиск отелей в SQLite по городу, числу гостей и бюджету;
- расчёт стоимости отеля за весь период;
- поиск транспорта по направлению;
- расчёт общей стоимости билетов для всех пассажиров;
- тестовый прогноз погоды;
- логи времени запросов к модели и выполнения инструментов;
- ответы, адаптированные для обычного терминала.

## Как работает агент

```text
Запрос пользователя
        ↓
OpenAI-compatible LLM
        ↓ tool call
Инструмент Go
        ↓ SQL-запрос
Локальная SQLite-база
        ↓ результат
LLM формирует ответ
```

1. Агент добавляет сообщение пользователя в историю диалога.
2. История и описания доступных инструментов отправляются модели.
3. Модель либо отвечает сразу, либо возвращает один или несколько tool calls.
4. Агент проверяет аргументы и запускает нужные инструменты.
5. Результаты инструментов передаются модели с соответствующими `tool_call_id`.
6. Модель составляет итоговый ответ. Цикл ограничен десятью итерациями.

## Структура проекта

```text
cmd/agent/          запуск CLI и загрузка .env
internal/agent/     история сообщений и agent loop
internal/database/  схема SQLite и начальное заполнение базы
internal/llm/       клиент OpenAI-compatible API
internal/tools/     интерфейс и инструменты агента
data/travel.db      локальная база, создаётся при запуске
```

## База данных

При первом запуске создаётся файл `data/travel.db` с двумя таблицами:

- `hotels` — название, город, цена за ночь, рейтинг и максимальное число гостей;
- `transport_options` — направление, тип транспорта, название, время отправления, продолжительность пути и цена за пассажира.

Начальные записи добавляются только в пустые таблицы, поэтому повторный запуск не создаёт дубликаты. Файл базы не требуется хранить в Git: приложение восстановит его автоматически.

Поиск отелей выполняется параметризованным SQL-запросом. Итоговая цена рассчитывается как цена за ночь, умноженная на количество ночей, после чего применяется ограничение бюджета.

## Требования

- Go 1.22 или новее;
- C-компилятор для `github.com/mattn/go-sqlite3`;
- ключ провайдера с OpenAI-compatible API.

На macOS C-компилятор можно установить вместе с Command Line Tools:

```sh
xcode-select --install
```

## Настройка

Создайте локальный файл настроек:

```sh
cp .env.example .env
```

Заполните `.env`:

```env
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_API_KEY=your-openrouter-api-key
LLM_MODEL=openrouter/free
LLM_TIMEOUT=180s
TRAVEL_DB_PATH=data/travel.db
```

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `LLM_BASE_URL` | Базовый URL OpenAI-compatible API | обязательна |
| `LLM_API_KEY` | Секретный API-ключ | обязательна |
| `LLM_MODEL` | Идентификатор модели | обязательна |
| `LLM_TIMEOUT` | Максимальное время одного запроса к модели | `180s` |
| `TRAVEL_DB_PATH` | Путь к SQLite-базе | `data/travel.db` |

Значения из `.env` загружаются программой автоматически. Добавлять ключ в `.env.example` или исходный код нельзя.

## Запуск

```sh
go run ./cmd/agent
```

Пример диалога:

```text
Планировщик путешествий запущен. Для выхода нажмите Ctrl+D.
> Хочу поехать из Москвы в Казань на выходные вдвоём.
Уточните максимальный бюджет на отель за весь период.
> 20000
...
```

Во время ожидания программа выводит диагностические сообщения:

```text
[agent] запрос к модели #1...
[agent] модель ответила на запрос #1 за 4.2s; tool calls: 2
[agent] запуск инструмента search_hotels...
[agent] инструмент search_hotels завершён за 1ms
```

Для выхода нажмите `Ctrl+D`.

## Ограничения

- данные об отелях и транспорте вымышлены;
- погода не загружается из внешнего сервиса;
- доступность транспорта пока не зависит от конкретной даты;
- бронирование и оплата не реализованы;
- бесплатные LLM в OpenRouter могут отвечать медленно или нестабильно;
- история диалога хранится только до завершения процесса.
